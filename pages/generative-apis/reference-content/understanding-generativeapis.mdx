## Overview

Scaleway's Generative APIs provide access to pre-configured, serverless endpoints of leading AI models, hosted in European data centers. This allows you to integrate advanced AI capabilities into your applications without managing underlying infrastructure. You can think of a Generative API as an on-demand expert. You send a specific request using a prompt, and it provides an answer, without you needing to know how the AI is built. A prompt is a natural language instruction or question.

## Key features

- Pre-configured and serverless endpoints: These APIs offer access to leading AI models, such as Llama or Mistral, without the need to manage infrastructure or deploy models yourself.
- Hosted in Europe: All models are hosted in Scaleway’s data centers located in Paris, France, ensuring compliance with European data protection regulations like GDPR.
- Pay-per-use pricing: The service is priced competitively based on the number of tokens used (per million tokens), allowing for cost-effective scaling. A token is the basic unit of text  that the AI uses to process and generate information.


## Example use of prompting
The example below shows how to send a specific request using a prompt.

### Scenario 

1. Go to the **AI** section in the Scaleway Console, and then click on **Generative APIs**.
2. Choose your AI model from the list, for example `mistral-small-3.2-24b-instruct-2506`.
The Playground chat appears.
3. Write a prompt in the Playground chat. For example, `Write a professional email to a client to announce that the documentation for Cloud Essentials for RabbitMQ is published for the Public Beta.`
The answer from the AI model appears in the Playground chat.
